The current shortlist

Choose by translation job

Current product pages emphasize different strengths. Avoid turning one platform's marketing claim into a universal accuracy ranking.

Google Translate

Free + app

Supports camera, offline language downloads, conversations, speech transcription, handwriting, saved translations, documents, and websites. Features depend on language and platform.

See official features

DeepL

Free + Pro

Offers text and file translation, with document workflows for PDFs, Word, PowerPoint, Excel, HTML, TXT, and other formats. Pro features support customization and larger business workflows.

Explore document translation

Microsoft Translator

App + API

Supports real-time conversations, menus and signs, offline use, websites, documents, and education workflows, with business text and speech APIs through Azure.

Explore Microsoft Translator

Papago

Free web app

Its current web interface exposes text, image, document, voice, and website translation modes, with dictionary and language-learning support. Coverage varies by language pair.
