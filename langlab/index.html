Popular Language Resources

Python

The official tutorial covers interpreter use, control flow, data structures, modules, I/O, errors, classes, the standard library, virtual environments, and packages. It assumes some general programming understanding.

Free docs Web Python

JavaScript

MDN's Guide progresses through grammar, types, control flow, functions, objects, classes, promises, modules, resource management, internationalization, and advanced topics.

Free docs Web JavaScript

Java

Dev.java provides current learning material for first applications, JShell, IDE workflows, records, generics, lambdas, collections, streams, virtual threads, modules, and more.

Free learning Web Java

Rust

The current Rust Book assumes Rust 1.90.0 or later with the Rust 2024 Edition and covers ownership, borrowing, structs, enums, modules, collections, error handling, generics, testing, smart pointers, concurrency, and idiomatic Rust.

Free book Web Rust

Reference discipline

Use the tutorial for concepts, the language reference for exact rules, the standard library docs for APIs, and release notes for version-sensitive behavior.

Tool-dependent App Reference

Practice projects

Rebuild one small tool three ways: a text processor, a JSON API client, or a command-line organizer. Compare readability, tests, performance, and error handling.

Self-directed Web Rust

Key Language Features

Learn the shape

Understand values, control flow, functions, data structures, modules, and the execution model.

Probe the edges

Use a REPL or local editor to vary inputs, trigger errors, and inspect what the runtime actually does.

Build and explain

Make a small CLI, web feature, data tool, or systems exercise and document the decisions you made.

Reference Docs

Quick lookups for APIs, libraries, and error troubleshooting.

Community Examples

User-contributed code and forums for best practices and Q&A.

Practice Evidence

Use small projects, tests, readable repositories, and explanations of your decisions as evidence of progress; official documentation links are not certification claims.

Use the Python Tutorial

A focused official starting point

The official Python Tutorial introduces the language and its system through concise examples. It is free and current, but it expects a basic understanding of programming rather than teaching programming from zero.

  • From interpreter basics to modules and classes
  • Use the interpreter for hands-on experiments
  • Links to the standard library and language reference
  • Examples spanning files, errors, packages, and data
  • Free documentation and freely available Python
Open Python Tutorial

The tutorial is free to read; pair it with a local Python installation for hands-on practice, and check the documentation for the version you are using.
