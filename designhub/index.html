A process that survives handoff

A beautiful screen is not the whole product. Keep the user goal, content, states, constraints, and implementation notes visible as the work moves from idea to build.

The current shortlist

Choose a tool for the job

These products overlap, but their strengths differ. Pick based on the artifact you need to make and the people who need to participate.

Figma

Free + paid

Collaborative design, prototyping, FigJam, Dev Mode, and a growing set of products. Starter is free with limited access; paid seats add files, libraries, handoff, and administration.

See Figma plans

Penpot

Open source

Open-source, browser-based design for teams. It supports responsive rules, CSS Grid and Flex layouts, interactive prototypes, real-time collaboration, design tokens, and code inspection.

Explore Penpot

Canva

Free + paid

Fast visual communication for posters, presentations, social content, documents, and more. Canva Free includes a drag-and-drop editor, templates, assets, storage, and limited AI access.

See Canva plans

FigJam

Inside Figma

Use collaborative whiteboarding for mapping, workshops, critique, and early alignment before turning the result into a detailed interface.

Explore FigJam

Penpot Devtools

Open standards

For design-to-code learning, inspect properties and CSS/SVG output while keeping implementation constraints close to the design conversation.

Read features

WCAG guidance

Open standard

Use the W3C Web Content Accessibility Guidelines as a reference for contrast, keyboard access, text alternatives, focus, and robust interaction states.

Read WCAG

Questions beginners ask

Yes, for learning fundamentals, small exercises, and portfolio prototypes. Limits appear when you need many private files, shared libraries, advanced handoff, or team administration.

Include the user flow, responsive behavior, content rules, component states, interaction details, accessibility expectations, assets, and unresolved questions. A link alone is not a specification.

Choose Figma when your class or collaborators already use its ecosystem; choose Penpot when open-source licensing, self-hosting, web standards, or design-to-code alignment are central learning goals.
