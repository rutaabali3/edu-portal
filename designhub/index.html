Popular Design Tools

Figma

Collaborative design, prototyping, FigJam, and Dev Mode. Starter is free with limited access and unlimited drafts; paid plans add broader file, library, handoff, seat, and administration capabilities.

Free + paid Web UI/UX

Penpot

Open-source design for teams, available as a hosted service or self-hosted. It supports responsive rules, CSS Grid and Flex layouts, interactive prototypes, real-time collaboration, design tokens, shared libraries, and code inspection using open standards.

Open source Web Graphics

Canva

Fast visual communication for posters, presentations, social content, documents, and more. Canva Free provides a starter set of templates, content, editing tools, storage, and AI features; premium content and higher allowances depend on the plan.

Free + paid Web Prototyping

FigJam

Use collaborative whiteboarding for mapping, workshops, critique, and early alignment before turning the result into a detailed interface.

Inside Figma Web Whiteboarding

Penpot Devtools

For design-to-code learning, inspect properties and CSS/SVG output while keeping implementation constraints close to the design conversation.

Open standards Web Open Source

WCAG guidance

Use the W3C Web Content Accessibility Guidelines as a reference for contrast, keyboard access, text alternatives, focus, and robust interaction states.

Open standard Web & Desktop Vector

Key Collaboration Features

Frame the flow

Write the user, goal, entry point, success state, and edge case before opening the visual canvas.

Prototype the risk

Prototype the interaction most likely to fail and test it with realistic content before polishing the surface.

Systematize the result

Use components, tokens, annotations, responsive rules, and accessible states so the work can be built consistently.

Whiteboarding

Visual brainstorming with digital sticky notes, diagrams, workshops, and flows; confirm the current plan and sharing limits before using it with a class or team.

Feedback Tools

Use comments and review links to collect feedback, then resolve decisions and record open questions rather than relying on a link alone.

Developer Handoff

Share measurements, properties, assets, annotations, component states, and implementation notes; generated code is a starting point, not a substitute for an agreed handoff.

The Most Popular Design Platform

Figma is a widely used browser-based design platform for collaborative files, prototypes, design systems, FigJam, and Dev Mode. Its Starter plan is free but limited, so verify file, library, seat, and feature boundaries before planning a team workflow.

  • Real-time collaboration, with plan- and seat-dependent access
  • Browser access plus supported desktop and mobile experiences
  • Built-in prototyping tools
  • Design systems and shared libraries on supported plans
  • Starter is free with limited access; paid seats expand team workflows
