Popular Coding Resources

freeCodeCamp

A free, project-based curriculum covering programming, DevOps, cybersecurity, AI engineering, and English for Developers, with current certifications including web development, JavaScript, Python, databases, APIs, and full-stack development.

100% free Web Full-Stack

MDN Learn

A free, self-paced beginner curriculum organized into Getting Started, Core, and Extensions, covering HTML, CSS, JavaScript, accessibility, version control, performance, security, testing, and modern web tooling.

Free Web Languages

GitHub Skills

Interactive courses inside GitHub that cover repositories, Markdown, Pages, Git, pull requests, merge conflicts, Codespaces, Actions, CodeQL, secret scanning, and current Copilot workflows.

Free Web Collaboration

GitHub Codespaces

A cloud development environment that opens from a repository, pull request, or commit. Personal Free accounts currently include 120 core hours—equivalent to 60 hours on a 2-core machine—plus 15 GB-month storage; usage beyond the quota can be billed.

60 hr/mo* Web Dev Env

Codecademy Basic

The $0 Basic plan includes selected course material, community support, learning resources, and limited practice. Projects, quizzes, full courses, skill paths, certificates, and career features are limited or require a paid plan.

Limited free Web Interviews

The Odin Project

A free, open-source full-stack curriculum that curates tutorials and courses, then asks learners to build portfolio-worthy projects with community support.

Free Web Web Dev

Key Coding Features

Foundations

Begin with HTML, CSS, JavaScript, or Python. Use guided exercises to learn syntax and the mental models behind it.

Projects

Build small, complete things: a page, a tool, a data script, or a game. Read documentation when you get stuck.

Proof of work

Use GitHub to document decisions, publish a demo, and ask for feedback. Certificates are useful; finished work is stronger.

Progress Trackers

Monitor your skill growth with badges and completion stats.

Version Control Intro

Learn Git basics integrated into platforms for team projects.

Cloud IDEs

Code in the browser without setup—perfect for beginners.

Try freeCodeCamp

Non-Profit Coding Bootcamp

freeCodeCamp is a donor-supported nonprofit with a free, project-based curriculum. It offers verified certifications and asks learners to complete five projects and pass their tests for each certification.

  • Project-based learning in the browser, editor, or mobile app
  • Current paths in web development, JavaScript, Python, databases, APIs, and full-stack development
  • Build projects and pass tests to earn verified certifications
  • Community, articles, tutorials, interview preparation, and job-search resources
  • Courses, projects, and certifications are free according to the official FAQ
Try freeCodeCamp Now

The official FAQ says the courses, projects, and certifications are free. The nonprofit is supported by donors, and availability or curriculum details should be rechecked on the official site over time.
